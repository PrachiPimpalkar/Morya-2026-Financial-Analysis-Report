# MORYA 2026 – Financial Data Analysis Dashboard

## Project Overview

MORYA 2026 is an end-to-end data analytics project developed to analyze and monitor financial transactions during Ganeshotsav 2026.

The project transforms raw Google Form responses into structured data and presents key financial insights through interactive dashboards. It covers the complete analytics workflow from **data collection and cleaning to KPI development, visualization, and reporting**.

## Business Objective

The dashboard was designed to answer questions such as:

* What is the total income and expenditure?
* What is the current net balance?
* Which expense categories contribute the most to spending?
* How much money has been collected?
* How much loan has been taken and how much remains outstanding?
* Which money lenders have the highest outstanding amounts?
* Which payment methods are used most frequently?
* How does income and expenditure change over time?

## Dashboard Pages

### 1. Overview

Provides a high-level view of financial performance through:

* Total Income
* Total Expense
* Net Balance
* Miravunk Collection
* Loan Outstanding

* Expense analysis by purpose
* Interactive filters

### 2. Loan Analysis

Focuses on financial obligations:

* Loan Received
* Loan Repaid
* Outstanding Loan
* Net Balance
* Outstanding loan by money lender
* Loan details
* Payment method analysis

### 3. Financial Report

Provides detailed transaction-level analysis:

* Booking-wise amount analysis
* Net balance trend
* Payment method distribution
* Transaction-level reporting
